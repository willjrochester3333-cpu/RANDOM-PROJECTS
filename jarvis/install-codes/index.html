J.A.R.V.I.S. Install Codes

One paste puts all of a Pi's J.A.R.V.I.S. files on it. The block is compressed, so it looks like random letters; the readable code is in the jarvis/ folder on GitHub. If any part of the paste goes missing, it stops with an error instead of installing broken code.

How to use

  1. Open the Pi's terminal in Raspberry Pi Connect.
  2. Click Copy on the block for that Pi below.
  3. Click in the terminal and paste with Ctrl+Shift+V or right-click, Paste. If the browser asks to allow the clipboard, allow it.
  4. Press Enter if nothing starts by itself.

CORE server (Raspberry Pi 5)

Setup starts by itself and takes 10 to 20 minutes the first time. Pasting it again later updates the server and keeps your password. At the end it prints the MQTT password: copy it somewhere safe, every other device needs it. Then type hostname -I to get the server's IP address and open http://THAT-ADDRESS/ in a browser to see the dashboard. With a USB microphone and speaker plugged in, say 'Hey Jarvis' once it is done.
